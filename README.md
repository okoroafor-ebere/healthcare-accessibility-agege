# Healthcare Accessibility in Agege, Lagos State

This repository contains my GeoDev Lab project on healthcare accessibility in Agege Local Government Area, Lagos State, Nigeria.

The project investigates geographic access to healthcare by identifying wards that are located more than 5 km from a health facility.

## Project Question

Which wards in Agege Local Government Area, Lagos State are more than 5 km from a health facility?

## Study Area

Agege Local Government Area, Lagos State, Nigeria.

## Data Sources

The project will use health facility and ward boundary data from GRID3, together with road network data from OpenStreetMap.
